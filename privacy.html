1. Introduction

Back2Goal ("the Service") is owned and operated by Sharon Bash, the sole founder and developer.

This Privacy Policy explains how data is processed when using the Service.

2. Overview

Back2Goal is designed as a privacy-first, local-first Chrome extension.

  • All functionality operates locally on your device
  • No personal data is sent to any developer-owned servers
  • No tracking, analytics, or advertising technologies are used
  • No third-party fonts, CDNs, or external scripts are loaded

3. Data Processed by the Extension

The Service processes limited data strictly for functionality:

a. Website Hostnames (Local Processing Only)

  • The extension reads the current tab’s hostname (e.g., example.com)
  • Used only in real time to determine whether a site should be blocked
  • Full URLs are not stored
  • Hostnames are not transmitted externally

👉 Important: We do not collect or store your browsing history.

b. User Settings (Stored Locally)

Stored using chrome.storage.local:

  • Blocked websites list
  • Focus schedule (start/end time, active days)
  • Reminder interval
  • Protection status
  • UI preferences

This data:

  • Remains entirely on your device
  • Is not transmitted externally
  • Is not accessible to the developer

c. License Data (PRO Features)

If you activate a paid version:

The following data is sent to Lemon Squeezy:

  • License key
  • Instance identifier
  • Instance name ("Back2Goal Chrome Extension")

Used only for:

  • License activation
  • License validation

4. Data Transmission

The Service does not transmit user data externally, except in the following limited cases:

a. License Activation & Validation (Lemon Squeezy)

Data sent:

  • License key
  • Instance ID
  • Instance name

This occurs:

  • When activating a license
  • When validating a license

👉 Important: If PRO is activated, license validation may occur automatically when the extension popup is opened.

👉 Additional clarification: No information about the user’s blocked websites, browsing habits, or schedules is ever attached to these license validation requests.

b. User-Initiated Navigation

The extension may open external pages only when triggered by the user, such as:

  • Payment checkout pages
  • Legal pages (Terms / Privacy)

These are standard browser navigations and not background data transfers.

c. No AI Training

Data processed by the Service is not used to train machine learning or artificial intelligence models. The Service does not transmit user data to any AI service providers, and no user content is used for model training purposes.

8. Permissions Explanation

storage

Used strictly to store your settings, blocklists, and focus schedules locally on your device.

tabs

Used to identify the hostname of the current tab for local matching against your blocklist and to trigger the focus overlay when a restricted site is accessed.

Host Permissions (api.lemonsqueezy.com)

Used exclusively to communicate with our payment provider to activate and validate PRO licenses. No browsing data is sent to this host.

Content Scripts (all_urls)

The extension injects a local script into websites to:

  • Verify the hostname in real time
  • Render the blocking overlay

👉 Important: This process happens locally.

The extension does not read, collect, or transmit:

  • Page content
  • Text
  • Form inputs
  • Any data from the websites you visit
